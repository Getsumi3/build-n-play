# BuildNPlay

> Ten games. Ten experiments. One developer. No deadlines.

A personal game development challenge to build 10 small games, explore different mechanics, and learn something new with every project.

## Games

1. One Button
2. Tiny Dungeon
3. Impossible Jump
4. One More Wave
5. The Room
6. Lost in Space
7. Tiny Shop
8. Last Player Standing
9. A Story in 5 Minutes
10. The Final Boss

## Tech Stack

- TypeScript
- Vite
- Canvas 2D
- SCSS + BEM
- ESLint + Prettier

## Follow the Journey

Building, experimenting, learning, and sharing along the way.

**No deadlines. Just games.**
